# Bakery OS

האפליקציה כוללת:
- מתכונים וכרטיסי ייצור
- הזמנות ותאריכי אספקה
- חישוב כפולות ועודפים
- תוכנית עבודה לפי ימים
- רשימת קניות לאחר הפחתת מלאי
- מלאי, תפוגה ורמות מינימום
- ספקים, מחירים, מרחק ועלות משלוח
- אומדן עלויות ורווחיות
- דוחות
- גיבוי JSON
- PWA
- חיבור Supabase לסנכרון בין מחשב לאייפון

## שימוש מיידי
פתחי את bakery_os_standalone.html. הנתונים יישמרו במכשיר שבו פתחת את הקובץ.

## שימוש כאפליקציה וסנכרון
פרסמי את קבצי התיקייה ב-Netlify, Vercel או GitHub Pages דרך HTTPS.
פתחי פרויקט Supabase, הפעילי Email Authentication והריצי את supabase.sql.
באפליקציה היכנסי להגדרות והדביקי Project URL ו-Publishable/Anon Key.
אל תשתמשי ב-Service Role Key בדפדפן.

## מחירי חנויות
ההשוואה מבוססת על מחירים ומרחקים שמוזנים ידנית. סריקה אוטומטית של רשתות דורשת API או מקור נתונים מאושר.
