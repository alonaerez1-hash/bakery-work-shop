עדכון Bakery OS v5 ל-GitHub

1. היכנסי למאגר bakery-work-shop.
2. לחצי Add file ואז Upload files.
3. גררי את חמשת הקבצים הבאים מתוך קובץ העדכון:
   index.html
   app.js
   styles.css
   sw.js
   manifest.json
4. אשרי החלפה של הקבצים הקיימים ולחצי Commit changes.
5. המתיני לפריסת GitHub Pages, פתחי את האתר ורענני אותו.
6. באייפון: סגרי את האפליקציה לגמרי ופתחי שוב. אם עדיין מוצגת גרסה ישנה, פתחי פעם אחת את כתובת האתר בספארי ורענני.

אין צורך להריץ שוב את supabase.sql.
הנתונים שכבר נשמרו אינם נמצאים בקובצי האתר ולכן אינם אמורים להימחק.
